# LibraDesk v0.1.1 — Windows installer with bundled runtime

LibraDesk is an offline-first personal PDF library for Windows. Organize PDFs where they already live, search Bengali and English, and read with saved progress, notes and bookmarks.

## Download and install

Download **LibraDesk_0.1.1_x64-setup.exe** from the assets below, run setup, then open **Import → Add folders**. Source-code ZIP/TAR archives are not installers. No Node.js, Rust or development tools are needed.

- Target: Windows 11 x64, Intel/AMD.
- Setup size: 224,490,298 bytes (~214.09 MiB).
- Includes Microsoft's full WebView2 Evergreen standalone prerequisite; if the runtime is missing, setup can install it locally without a separate runtime download.
- Current-user installation. Organizations may restrict application/runtime setup.
- Suggested planning minimum: 8 GB RAM, Windows 11-compatible dual-core x64 CPU, 2 GB free working space plus PDFs/cache/backups, 1280 × 720 display. Prefer 16 GB RAM and SSD app storage for large libraries. These recommendations are not a measured hardware floor.
- The app and setup are unsigned. Verify the official asset/checksum before deciding whether to run an unknown-publisher prompt. Do not disable security software.
